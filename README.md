# Python Reminder App

## 概要

Pythonで作成した、日々の予定を管理するシンプルなリマインダーアプリです。

ターミナルから予定を入力し、JSONファイルに保存します。また、当日登録されている予定をWindowsのデスクトップ通知で表示します。

Pythonの基礎学習を目的として、データ管理やファイル操作、外部ライブラリの利用を実践しました。

## 主な機能

- パソコンの日付を自動取得
- ターミナルから予定を入力
- 複数の予定をリストで管理
- 「終了」と入力して予定入力を終了
- JSONファイルへのデータ保存
- JSONファイルからのデータ読み込み
- 当日の予定を取得
- Windowsのデスクトップ通知で予定を表示

## 使用方法

### 1. 必要なライブラリをインストール

```bash
pip install winotify
```

### 2. プログラムを実行

```bash
python reminder.py
```

### 3. 予定を入力

ターミナルに表示される入力欄に予定を入力します。

「終了」と入力すると予定の入力を終了します。

### 4. データ保存・通知

入力した予定をJSONファイルに保存し、当日の予定がある場合はWindowsのデスクトップ通知に表示します。

## データ管理について

予定データは `tasks.json` に保存します。

日付をキー、予定をリストとして管理する辞書構造を使用しています。
